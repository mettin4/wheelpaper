# The Wheelpaper
The Squeekchain whitepaper, made playable. Live at https://wheelpaper.vercel.app
Difficulty simulator, supply clock and merge pyramid, implemented from the whitepaper's own integer formulas.
Unofficial. Not affiliated with Squeekchain. Built by @0xmeto_

Reads live Sepolia state (block height, work units, distance) from the public Squeekchain API, with a static fallback when the feed is unreachable.
